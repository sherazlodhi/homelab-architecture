Platform Architecture Decisions (ADR Summary)

Decision Area Design Approach Architectural Trade-off & Rationale
Workload Partitioning Multi-tier (Microcontrollers → SBC → x86) Isolate low-jitter real-time I/O from heavy CPU-intensive AI model inference.
Local AI Model Serving RAM-locked Ollama Qwen-2.5 1.5B (AVX-512) Eliminates swap and disk cold-start latency; satisfies strict real-time SLA.
Audio Latency Budget Sentence-chunked MP3 HTTP streaming proxy Cuts user perception latency from ~5s down to 1.2s without waiting for complete text synthesis.
Security & Ingress Local ACL Reverse Proxy + Cloudflare Zero Trust Exposes zero administrative or telemetry ports to public network without authentication.
